Write value as a minimal big-endian byte sequence.

Value 0 produces one 0x00 byte; the caller is responsible for treating the empty-integer case (value==0 -> RLP 0x80) before calling this function.

Parameters

[out]outOutput buffer (exactly 8 bytes; up to 8 used).
