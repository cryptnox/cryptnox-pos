Detailed Description

cryptnox-pos entry point: touchscreen USDC payment terminal.

Drives the amount → confirm → sign → broadcast flow on the Cheap Yellow Display, signing EIP-1559 USDC transfers on a Cryptnox card via PN532.

UI-task callback: forward a touch event to the main task queue.

Runs in the UI task context. A Cancel tap also raises the atomic s_user_cancelled flag so the in-flight signing flow can abort without waiting for the queue to drain.
