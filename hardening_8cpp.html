void pos_handle_anomaly ( const char * where)

Report an anomaly: bump a self-checked persisted counter, log it, and keep a local ring buffer for on-site inspection.

Fails the current transaction closed (the caller's gate returns FALSE32); never bricks — a keyless POS holds no secret to protect (§3.3). Firmware only (NVS + esp_log); defined in hardening.cpp.
