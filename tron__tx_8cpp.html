◆ tron_trc20_param_hex()

size_t tron_trc20_param_hex ( const char * to_hex,
uint64_t amount,
char * out,
size_t out_size )

ABI-encode the arguments of transfer(address,uint256), hex.

Two 32-byte words, no selector: the recipient left-padded (its 0x41 Tron prefix dropped — the ABI address word holds the bare 20-byte key hash) and the amount big-endian. This is exactly what the HTTP API's parameter field wants, and exactly what must reappear inside the node's raw_data.

Parameters
[in]to_hexRecipient, TRON_ADDR_HEX_LEN hex chars, "41"-prefixed.
[in]amountToken amount in base units.
[out]outDestination, NUL-terminated on success.
[in]out_sizeCapacity of out (>= TRON_TRC20_PARAM_HEX_LEN + 1).
Returns
TRON_TRC20_PARAM_HEX_LEN on success, 0 on bad input or overflow.

Verify that a node-serialised raw_data really transfers what we asked.

Parses raw_data_hex as a Transaction.raw protobuf: exactly one TransferContract whose value is exactly owner (field 1), to (field 2) and amount (field 3); only the reference-block, expiration and timestamp fields besides it; no fee_limit, memo, authorities or scripts; no repeated field. Fails closed — the caller must decline the payment rather than sign it.

Parameters
[in]raw_data_hexHex of the node's raw_data protobuf.
[in]owner_hexSender, TRON_ADDR_HEX_LEN hex chars, "41"-prefixed.
[in]to_hexRecipient, same form.
[in]amount_sunAmount in sun (1 TRX = 1e6 sun).
[in]now_msCurrent Unix time in ms; must be non-zero.
[out]expiration_msraw_data.expiration on success; may be NULL.
Returns
true only if raw_data is exactly the requested transfer and expires within TRON_TX_MAX_EXPIRY_MS of now_ms.

Verify that a node-serialised raw_data really is the TRC-20 transfer we asked for.

The TRX sibling of this check is tron_tx_contract_ok, with the same strict parse; a token transfer is a TriggerSmartContract instead, whose value must be exactly (call_value 0 may be explicit):

0a15 owner | 1215 contract | 2244 a9059cbb | to-word | amount-word

The contract address decides which asset moves. The fee_limit (raw_data field 18) must be present and equal to fee_limit_sun: it caps the TRX a failed call may burn.

Parameters
[in]raw_data_hexHex of the node's raw_data protobuf.
[in]owner_hexSender, TRON_ADDR_HEX_LEN hex chars, "41"-prefixed.
[in]contract_hexToken contract, same form.
[in]to_hexRecipient, same form.
[in]amountToken amount in base units; must be non-zero.
[in]fee_limit_sunFee cap in sun, as requested; must be non-zero.
[in]now_msCurrent Unix time in ms; must be non-zero.
[out]expiration_msraw_data.expiration on success; may be NULL.
Returns
true only if raw_data is exactly the requested call.
