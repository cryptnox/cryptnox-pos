Detailed Description

A token's contract, dual-stored.

The contract decides which asset moves, so it gets the same dual store (§3.2/§7.1) and reconciles as the recipient. One per selection, indexed by pos_chain_t (USDT on Ethereum and Polygon are different deployments). A native coin's slot stays empty.
