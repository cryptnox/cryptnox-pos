Cryptnox POS: Open-Source Crypto Payment Terminal (ESP32 Dev Kit)

Covers cryptnox-pos v1.0.0.

cryptnox-pos is open-source firmware that turns a low-cost ESP32 touchscreen board, the ESP32-2432S028 “Cheap Yellow Display” (CYD), plus a PN532 NFC module into a tap-to-pay crypto payment terminal. The customer taps a Cryptnox Hardware Wallet card, the card signs the transfer inside its secure element, the terminal broadcasts it to the chain and shows Approved only once the transaction is mined.

What it is, and what it is not

Important

Reference and educational dev kit, not a tamper-resistant payment terminal. The ESP32 is not a secure microcontroller and has no protected RAM. The optional secure build protects secrets at rest and locks the boot chain, but at run time the card PIN (typed on the screen, never stored) and the Wi-Fi password sit in plaintext RAM. What keeps the money safe is the card: private keys never leave the Cryptnox Hardware Wallet, so a compromised terminal still cannot sign a payment the cardholder did not tap for.

It is not the C-WaaS terminal. Cryptnox’s C-WaaS blockchain card scheme runs issuer-managed cards through terminals with a Secure Access Module and issuer co-signing, for banks and card programmes. cryptnox-pos is the self-custody counterpart: anyone with a Cryptnox Hardware Wallet card can pay, there is no issuer in the loop, and the merchant receives the funds directly at an address they configured. How the C-WaaS terminal differs is described in How the C-WaaS POS terminal works.
