Detailed Description

The config portal's document — the HTML/CSS half and the script half.

Lifted out of provision.cpp, which is the HTTP server: the two literals below were ~700 of its 2100 lines and are read by exactly one function there (page_get, which concatenates them into one chunked response). Nothing else includes this, so the statics are one copy in one translation unit.

Checked by tools/check_portal_page.py, which extracts both literals from this file, verifies the script parses and that every id the script reaches for exists in the markup — and emits the script for tools/test_portal_render.js. Edit the page here; the checks run from scripts/checks.sh.
